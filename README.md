# golfans_members-connect

**Golfans × Members' Connect プラットフォーム**
宝塚ゴルフ倶楽部 会員専用ポータル ＆ クラウド同期MVP

## アーキテクチャ
- **フロントエンド**: PWA / HTML5 / CSS3 / JavaScript (Vanilla)
- **ホスティング**: Cloudflare Pages (`https://takarazuka.golfans.com`)
- **API**: Cloudflare Pages Functions (`/api/sync`)
- **データベース**: Supabase (PostgreSQL + RLS)
